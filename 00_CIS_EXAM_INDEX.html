§4 — How to use each bank effectively / كيف تستخدم بنك الأسئلة

Open component:ApplicationLeave Requests

4.1 Three-pass technique

Open component:ApplicationLeave Requests
Pass Goal Time per question
1st pass — Diagnostic Find your weak areas; don’t worry about score 60s
2nd pass — Learning Read the explanation for every wrong answer; redo lab 3-5 min
3rd pass — Confidence Aim for 90%+ accuracy; focus on edge cases 30s

4.2 Question type strategies

Open component:ApplicationLeave Requests
Type Strategy
“All of the above” / multiple correct Read each option independently; verify with XXXXX
“Best practice” questions Choose the most OOTB, lowest-customization answer
Script questions Trace execution mentally; pay attention to current.update(), async, before/after
CMDB IRE questions Always check: Identifier rule + Reconciliation source
CSDM questions Know the 4 domains by heart (Foundation, Design, Build, Manage)
Workflow questions Flow Designer = preferred; Workflow = legacy
ACL questions Deny wins; field-level evaluated after record-level; scope matters

4.3 Lab-driven studying (recommended)

Open component:ApplicationLeave Requests

Instead of reading Q+A linearly, do the lab first, then answer the questions related to that lab. This builds muscle memory:

Lab → Question → Verify on PDI → Re-read explanation → Move to next lab

This is how the §19 sections in each module file are structured.
