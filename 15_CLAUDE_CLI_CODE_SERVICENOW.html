Part 1: Paste Into Studio Instructions

Purpose

Standard workflow for copying scripts from disk or Scripts portal into Studio forms.

Navigation path

All > Studio → HR Leave → open target object → Script field

Step-by-step create

  1. Application picker = HR Leave (x_786686_hr_leave).
  2. Update Set HR Leave – Build = current.
  3. Open the chapter Part for the object (form fields + navigation path).
  4. Open matching file under HR_Leave_App/src/ OR Scripts portal.
  5. Copy entire script — include header comment block.
  6. Paste into Studio Script field (Business Rule, Script Include, Record Producer, Widget server, etc.).
  7. Save → run that Part Verify + Demo checklist.

Do not paste into Global-scoped records. Confirm Application = HR Leave on the form before save.
