Deployment sequence:

  1. Freeze Update Set and peer review.
  2. Export/import or retrieve; Preview before Commit.
  3. Resolve collisions deliberately—never skip without evidence.
  4. Run ATF smoke suite.
  5. Validate ACLs using impersonation.
  6. Validate Flow, events, notifications, reports, and integration.
  7. Record rollback steps and release evidence.

Gate G: no unresolved Update Set errors; ATF passes; audit trail and rollback plan are documented.
