Step-by-step create

  1. Flow Designer → Create Flow → Name HRLX Leave Approval, Application HR Leave.
  2. Add trigger → Record Updated → table req_v2 → condition u_state is submitted + changes.
  3. + → Ask for Approval → fill Action 1 table → Rules: Anyone approves → Done.
  4. + → Flow Logic → If → condition "approval was Approved".
  5. Yes branch → Update Record → u_state = approved.
  6. Else branch → Update Record → u_state = rejected.
  7. Save → fix any red errors (missing approval rule is common).
  8. Test → pick sample submitted req_v2 → Run test.
  9. Publish → Publish new version → wait for Published status.

Verify checklist

  • Submitted req creates sysapproval_approver for manager.
  • Approve → u_state approved → BR3 audit + BR4 event.
  • Reject → u_state rejected.

Demo / test

  1. employee1 submits leave (UI Action or catalog).
  2. manager1 → My Approvals → Approve.
  3. Verify state, audit_v2, bal_v2 updated.
