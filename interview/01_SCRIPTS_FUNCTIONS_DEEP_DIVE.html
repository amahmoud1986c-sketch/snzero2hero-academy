Part 2 — Our Business Rules

Part 4 — GlideRecord patterns

Open component:ApplicationLeave Requests
var gr = new GlideRecord('table');
gr.addQuery('field', 'value');
gr.addActiveQuery(); // active=true
gr.orderByDesc('sys_created_on');
gr.setLimit(1);
gr.query();
if (gr.next()) {
 gr.field = 'newValue';
 gr.update();
}

// Insert
gr.initialize();
gr.field = ‘x’;
var sysId = gr.insert();

// Secure (respects ACL)
var grs = new GlideRecordSecure(‘table’);

Interview: When use GlideRecordSecure? — Service Portal، multi-tenant، أي سياق المستخدم النهائي.
