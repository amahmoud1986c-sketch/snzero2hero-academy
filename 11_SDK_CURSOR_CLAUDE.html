Rule 0 — Before any object (Application + Update Set + Studio)

Repeat these checks before creating or editing any application file. This section is also section 00 Update Set — create the capture set first.

  1. Application picker — top-right globe / application menu → select HR Leave (x_786686_hr_leave). Never leave Global selected when creating scoped artifacts.
  2. Update Set — All → System Update Sets → Local Update Sets → New:
    FieldValue
    NameHR Leave – Build
    ApplicationHR Leave
    StateIn Progress
    DescriptionCaptures all HR Leave lab artifacts
    After submit: open the record → click Make Current. Direct list: {BASE}/sys_update_set_list.do
  3. Open Studio — {BASE}/$studio.do → confirm header shows HR Leave.

If artifacts land in Global scope, delete them and recreate under HR Leave. ACLs and events created globally will not behave correctly for this app.

Part 1: Daily Workflow in Studio

Purpose

Repeatable steps every time you create or edit HR Leave artifacts.

Navigation path

All > Studio → HR Leave application

Step-by-step create

  1. Set Application picker to HR Leave (x_786686_hr_leave).
  2. Set Local Update Set current (HR Leave – Build).
  3. Open Studio → select HR Leave.
  4. Create Application File → choose type (Table, Business Rule, Client Script, Script Include, …).
  5. Fill every form field from the matching chapter Part section.
  6. Paste script from embedded <pre> blocks or Scripts portal.
  7. Save → open list/form URL → run Verify + Demo for that Part.

Verify checklist

  • Customer Updates shows new artifact in HR Leave – Build.
