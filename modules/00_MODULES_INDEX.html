كيف تفعّل أي بلجن (طريقة عامة تنطبق على كل موديول)

Open component:ApplicationLeave Requests

معظم موديولات ServiceNow تُفعّل عبر Plugins، وبعضها يحتاج طلب من Store.

الطرق الثلاث:

  1. Plugins (الداخلي):
    Navigate: All > System Definition > Plugins — Open direct
    ابحث عن اسم البلجن ثم Activate.

  2. Store / Apps (المستحسن للموديولات الكبيرة):
    Navigate: All > System Applications > All Available Applications > All — Open direct
    أو من: https://store.servicenow.com
    ثم Request / Install.

  3. Guided Setup (بعد التفعيل):
    Navigate: All > Guided Setup — Open direct
    اتبع المراحل لكل موديول.

تنبيه مهم:
فعّل دائمًا على Sub-Production أولًا (Dev/Test) ثم انقل عبر Update Set أو Clone.
