1) Overview & Business Value

Open component:AssetsHardwareStockroomsPurchase Orders

ITAM manages the financial and operational lifecycle of IT assets from request → procure → receive → deploy → maintain → retire. — ITAM = إدارة أصول تقنية المعلومات (عتاد + برمجيات + مخزون + عقود). الهدف: معرفة ماذا تملك، أين هو، من يستخدمه، كم يكلف، وهل البرمجيات مرخّصة بشكل صحيح.

Q: What is the difference between HAM and SAM?
A: HAM manages physical hardware lifecycle and stockrooms. SAM manages software licenses, entitlements, and compliance.

Q: ITAM vs CMDB?
A: CMDB is configuration and service impact. ITAM is asset lifecycle, cost, stockroom, and licensing. They integrate via CI link.

12. Asset lifecycle state machine

function setState(asset, newState) {
 var allowed = {
 '6': ['1', '7'], // in_stock → in_use | retired
 '1': ['3', '7'], // in_use → in_maintenance | retired
 '3': ['1', '7'], // in_maintenance → in_use | retired
 '7': ['8'] // retired → disposed
 };
 var current = asset.install_status + '';
 if (!allowed[current] || allowed[current].indexOf(newState + '') < 0) {
 gs.addErrorMessage('Illegal state transition ' + current + ' → ' + newState);
 return false;
 }
 asset.install_status = newState;
 asset.update();
 return true;
}

}
