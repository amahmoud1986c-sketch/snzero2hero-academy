Part 1: Seed Data

Purpose

Lab employee, manager link, and opening balance for E2E demos.

Navigation path

All > System Definition → Scripts – Background

Prerequisites

  • Chapters 01–02 complete (tables, users, properties).

Step-by-step create

  1. Lookup sys_ids for employee1 and manager1 users.
  2. Run background script below as admin, Application = HR Leave.
  3. Verify employee_v2 and bal_v2 rows.

Full script (paste-ready)

(function () {
  var empUser = 'PASTE_EMPLOYEE1_SYS_ID';
  var mgrUser = 'PASTE_MANAGER1_SYS_ID';
  var emp = new GlideRecord('x_786686_hr_leave_employee_v2');
  emp.initialize();
  emp.u_user = empUser;
  emp.u_employee_id = 'E-1001';
  emp.u_department = 'People Ops';
  emp.u_manager = mgrUser;
  emp.u_join_date = '2024-01-15';
  emp.u_grade = 'G5';
  var empId = emp.insert();
  var bal = new GlideRecord('x_786686_hr_leave_bal_v2');
  bal.initialize();
  bal.u_employee_ref = empId;
  bal.u_year = 2026;
  bal.u_leave_type = 'annual';
  bal.u_entitled = parseInt(gs.getProperty('x_786686_hr_leave.config.annual_days', 20), 10);
  bal.u_used = 0;
  bal.u_remaining = bal.u_entitled;
  bal.insert();
  gs.info('Seeded employee=' + empId);
})();

Verify checklist

  • employee_v2 links employee1 → manager1.
  • bal_v2 year 2026 with entitled from property.
