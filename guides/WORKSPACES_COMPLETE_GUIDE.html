9. Best Practices

Open component:UI BuilderExperiencesApp Configs

Performance

Open component:UI BuilderExperiencesApp Configs
1. **Limit Data Fetching**
   - Use pagination (limit: 50-100)
   - Fetch only needed fields
   - Use aggregates for counts

2. **Lazy Loading**
   - Load details on demand
   - Defer non-critical components

3. **Caching**
   - Cache static reference data
   - Use client state for filters

Security

Open component:ACLsRolesGroupsUsers
1. **Data Resources**
   - Always filter by user context
   - Use ACLs on tables
   - Validate input parameters

2. **Actions**
   - Check permissions before action
   - Log sensitive operations
