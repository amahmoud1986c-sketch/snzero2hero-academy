3A — Open Otto / Now Assist on the instance (≈90 sec)

  1. Open assist
    • Direct: {BASE}/now/assist
    • Or click the Otto / Now Assist / sparkle icon in the instance header (name varies by release).
    • Filter navigator fallback: type Now Assist or AI Experience.
  2. Confirm panel loads — Chat / Ask visible. If blocked, check license + Now Assist plugins.
  3. Run one safe lab prompt (pick one):
    PromptWhat you verify
    List my open incidentsReturns INC numbers only from accessible data
    Summarize this incident (open an INC first)Uses record context
    What is my leave balance? (if HR Leave skills exist)Scoped HR Leave skill / VA topic
    How do I request annual leave?Knowledge / catalog guidance — no write if not intended
  4. Note the trail — skill name, agent, or flow mentioned in the answer UI (you will match this in Control Tower inventory later).
  5. Optional action — if Otto offers “create / update / assign”, cancel on lab unless you intend to test write paths.

3B — Open Workflow Data Fabric / data paths (≈60 sec)

  1. Filter navigator search (try in order):
    • Data Fabric
    • Integration Hub
    • Remote Tables
    • Flow Data / Connections
  2. Useful direct URLs to try:
    • {BASE}/now/assist — assist surface
    • {BASE}/$restapi.do — REST API Explorer (integration check)
    • {BASE}/sys_alias_list.do — Connection aliases
    • {BASE}/sys_rest_message_list.do — REST Messages
    • {BASE}/sys_db_object_list.do?sysparm_query=nameLIKEremote — remote-related tables
  3. Discuss with team: Which sources should agents read for HR Leave / ITSM? CMDB only? External HRIS? Block PII fields.

3C — Close the loop with Control Tower (≈30 sec)

  1. Re-open {BASE}/now/ai-control-tower
  2. Search AI Inventory for the skill/agent name you saw in Assist.
  3. Confirm: owner, risk stage, whether it is governed.

Functions — Otto / Assist (detailed)

Conversational ask

Natural language Q&A and “do this work” requests.

Context awareness

Uses open record / user / role to ground answers.

Skill routing

Picks Now Assist skill, agent, or flow for the intent.

Execute / finish work

Creates or updates work through platform workflows — not shadow IT.

Cross-product assist

ITSM · ITOM · SPM (Autonomous IT) in one assistant surface.

History & audit

Conversation and actions remain reviewable for support/governance.

Voice / multimodal*

Where licensed — voice agents & richer AI Experience.

Employee + agent UX

Same assistant pattern for self-service and fulfiller work.

Functions — Workflow Data Fabric (detailed)

Connect sources

CMDB, platform tables, external systems via Integration Hub / remote data.

Contextualize

Shape data so agents get usable, timely context.

Feed agentic AI

Supplies tools/skills with facts instead of hallucinations.

Access policy

Limit which identities/agents can read which sources.

Trust + CMDB

Align AI context with CSDM / CI relationships.

Ops readiness

Support Autonomous IT demos with real ops data paths.
