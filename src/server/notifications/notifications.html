Notifications — Complete Setup (Email · Events · All Fields)

Table: sysevent_email_action (Notification)
Scope: HR Leave (x_786686_hr_leave)

Fixes common mistakes:
- Table = HR Employee on notification form → wrong — must be Leave Request (x_786686_hr_leave_req_v2)
- Event not registered → notification never sends
- BR2/BR4 not active → event never queued
- PDI email not configured → notification runs but no mail
- Users/Groups in fields empty → no recipient

الأسلوب: عربية + إنجليزية تكمّلان بعضهما — بدون ترجمة حرفية لأسماء الشاشات.
