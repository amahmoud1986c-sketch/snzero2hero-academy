Phase 2 — Admin: Default ACLs (fixes your red error)

Open component:REST API ExplorerScripted RESTREST MessagesConnections

Default ACLs is mandatory on Scripted REST Service. You must attach at least one ACL before Submit. — حقل Default ACLs إلزامي — بدون ACL لن يقبل Submit (كما في صورتك).

Method A — Create ACL from the lock icon (recommended on New form)

Open component:ACLsRolesGroupsUsers
  1. Open Scripted REST New form (after Phase 0 — app = HR Leave).
  2. Fill Name and API ID first (see Phase 3 table).
  3. Go to tab Security.
  4. Find Default ACLs (red asterisk).
  5. Click the lock icon (or +) next to Default ACLs → New ACL record opens.

Fill the new ACL:

ACL field Value
Active true
Operation execute
Type scripted_rest_api (or Scripted REST API in UI)
Scripted REST API (may auto-link after parent saves — if empty, save API first then edit ACL)
Requires role x_786686_hr_leave.integration
Admin overrides false (prod) / true (lab only)
Advanced false

For lab testing add second ACL or add role admin on same ACL so your admin user can test in Explorer.

  1. Save ACL → return to Scripted REST form.
  2. Default ACLs list collector → add the ACL you created.
  3. Now Submit works.
