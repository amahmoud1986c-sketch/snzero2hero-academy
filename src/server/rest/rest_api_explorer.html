Path A — Table API (recommended first — no custom script)

Open component:TablesLeave RequestsEmployeesBalancesAuditREST API ExplorerScripted RESTREST MessagesConnections

Use when external system only needs to create/read/update leave records.

Setting Value
Namespace now
API name Table
Table x_786686_hr_leave_req_v2
Method POST (create) / GET (read) / PATCH (update)

Request URL (shown by Explorer):
/api/now/table/x_786686_hr_leave_req_v2

POST body example (Request Body tab):

{
 "u_requested_for_user": "<sys_user sys_id>",
 "u_employee_ref": "<employee_v2 sys_id>",
 "u_leave_type": "annual",
 "u_start_date": "2026-06-01",
 "u_end_date": "2026-06-05",
 "u_state": "submitted",
 "u_reason": "API test from REST API Explorer"
}

Steps in Explorer:
1. Select namespace now → API Table.
2. Choose table x_786686_hr_leave_req_v2.
3. Method POST → paste JSON in Request body.
4. Click Send.
5. Check Response (201 + result object) and verify list x_786686_hr_leave_req_v2.list.

Copy for external team:
- Copy as cURL (button in Explorer) → gives exact URL + headers for HRIS team.
