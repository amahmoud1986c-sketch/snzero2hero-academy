Steps

Open component:REST API ExplorerScripted RESTREST MessagesConnections
  1. Open REST Message HRLX ERP Push Decision
  2. Related list HTTP Methods → open Push Decision (POST)
  3. Click Send / Test / Preview (label varies by release)
  4. When prompted for test values:
    - Record: pick a leave request sys_id (approved/rejected)
    - Variable employee_id: enter EMP001 (or value from linked employee)
  5. Review Response panel:
    - 200 / 201 / 204 = success
    - 401 / 403 = fix Connection & Credential Alias
    - 404 = wrong endpoint property URL
    - 400 = ERP rejected JSON — fix body template
  6. If using webhook.site — open webhook URL and confirm JSON received

Troubleshooting

Only Default GET exists Create POST method §3
Test sends GET Open POST method, not GET
Empty endpoint Set property erp_endpoint
401 Unauthorized Credential alias + auth on method
Variables empty in body Set employee_id in Variables or Test form
Works in Test, fails in Flow Flow runs as different user — use system/alias

RESTMessageV2 by name (uses your REST Message config):

var gr = current; // leave record
var empId = '';
if (gr.u_employee_ref) {
 var e = gr.u_employee_ref.getRefRecord();
 empId = e.getValue('u_employee_id');
}
var rm = new sn_ws.RESTMessageV2('HRLX ERP Push Decision', 'Push Decision');
rm.setStringParameter('employee_id', empId);
// optional: rm.setEccParameter('skip_sensor', 'true');
var resp = rm.execute();
